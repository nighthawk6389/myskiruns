// Beaver Creek's 2025-26 trail map (VistaMap's painting). The resort
// publishes it only as an image (Vail Resorts' CDN, 4990x4453 px: the map
// image); skimap.org keeps the 2023-24 export of the same artwork as a vector
// PDF (map 25267), registered on the image (median residual 0.09 px). The
// two differ only in lodge icons, and in Dakota Skiway, which the 2025-26
// image adds at Arrowhead (its name and dotted line traced on the image).
// Lines are the PDF's 0.66 pt green, blue and black strokes (dashed: roads
// and catwalks; dotted: homeowner skiways, one of them drawn as filled dots);
// names are outlined glyphs (pdf_glyphs.py, shapes read on contact sheets:
// letters.json). Each run's symbol is printed on its line, often partway
// along it, the name beside it: a piece is named by the symbol on it or the
// name at its end, or settled on a crop (decisions.py). Names are spelled as
// the trail report spells them (report.json: the terrain feed, February
// 2026), or, where it lists the run in parts (Kestrel Upper, Middle and
// Lower; Peregrine; Larkspur; Cinch...) or by another name (BC Expressway:
// the map's Beaver Creek Mountain Expressway; Pines/Chateau: Borders-Pines-
// Chateau Skiway; Stirrup: Upper and Lower Stirrup; Stone Creek Chutes: Upper
// and Lower), as the map prints them; where it prints a part's own symbol, the
// parts are trails as the report names them: Centennial's Hohum, Spruce Face,
// Willy's Face and Finish Face (its Flats, unmarked, left to Willy's Face),
// and President Ford's and Stacker, whose lines turn blue at a square under
// the Strawberry Park lift (- Upper and - Lower). Where the map's symbol and
// the report differ, the map's is kept: Borders and Ridge Rider (blue squares;
// the report green), Goshawk Upper, Heads Up, 4 Get About It and Royal Elk
// Glade (double diamonds; black), Ptarmigan and Ruffed Grouse (diamonds;
// double black), Sheephorn - Escape (a circle; blue). Wapiti prints a diamond
// by its name and a square on its line above and below it: black. The kids'
// adventure zones printed on the map are markers (the box listing them also
// names Ripperoo's Retreat, Bear Cave and Gold Mine, printed nowhere else:
// left out). Left out too, printed nowhere on this map: the report's
// Beginner Area Ch. #2, Camp Robber Rd and Golden Eagle Connector (the black
// traverse with two diamonds from West Fall Road to Golden Eagle is probably
// it, but prints no name). Toyota Race Center: its course, the red line by
// its logo (no symbol: the report's blue). x/y/baseY/width are unused layout
// fields.
