// Sugarloaf's 2025-26 trail map from sugarloaf.com's trail-map page: one
// vector PDF page over a low-resolution painting (the map image is the vector
// layer over a smooth upscale of the painting). Trail lines are strokes in the
// difficulty colours; names are outlined glyphs (text on the east side) on
// label boxes in a gap of their lines, each run's symbol at one end of its
// label (each glyph shape read once, then decoded:
// tools/trailmap/resorts/sugarloaf/). Glades and connecting trails are red
// numbered circles referring to the key below the map: a circle printed on a
// line names the line under it. The Snowfields (the summit) are also drawn in
// an inset, a raster whose lines were traced on crops: a Snowfields run has an
// overlay on the main map and in the inset. The rest was settled on zoomed
// crops (decisions.py). Names are as printed (U., M., L.: upper, middle,
// lower). Difficulty: the symbols printed by the names; a run with none takes
// its line's colour. Golden Road (orange dashes) and Logging Road (blue
// dashes) are the legend's routes; Golden Road gets the default, blue. Key
// circles in the trees with no line are glades, markers at their circles
// (black unless rated). Winter's Way Ext. (circle 11 with a double diamond),
// West Sluice Chute (circle 20, no symbol: black, as its neighbours) and the
// back side's five chutes (circles 70-74 in the inset, no symbols: double
// black, as every Snowfields run the inset rates) have no line: markers.
// Elevation is the summit as printed. x/y/baseY/width are unused layout
// fields.
