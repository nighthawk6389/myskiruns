// Steamboat's 2026-27 trail map: the image steamboat.com links (2400x1682 px;
// the resort publishes no PDF). Its vector layer is read from the resort's
// interactive map (resorts-interactive.com map 1800), whose SVG draws this
// artwork's trail lines, names and symbols again, grouped by trail name
// (tools/trailmap/vicomap.py parse --detail). It is registered on the image
// (on its painting, then fitted on the image's blue line ink), each line routed
// onto the print's own line (the cheapest path through the print's line pixels
// near it), and each piece named by its group (resort.GROUPED). Where the
// 2026-27 artwork was redrawn (Concentration, Rudi's Run, Vagabond's head,
// Bashor and Bear Claw by the parks) the print's lines were traced instead
// (decisions.py, tools/trailmap/trace_ink.py). Names are each group's letters
// on the image; a symbol is the group's square, circle, diamond or double
// diamond, and advanced intermediate (a blue square with a black diamond, its
// line blue under black dashes) is blue. Names are spelled as the trail report
// spells them (report.json: the mtnpowder feed); its ratings all agree with the
// map's. Chute 1, 2 and 3 and Triangle 3 take the number their group id
// carries. All Out ("closed to public") and the snowshoe trails (Duster,
// Chisholm Trail) are left out; the report's boundary gates aren't on the map.
// The terrain parks, printed in their orange areas and in no group, are placed
// by hand: Rabbit Ears Terrain Park, Maverick's Superpipe (the report's
// Maverick's Half Pipe), Maverick's Terrain Park, Lil' Rodeo Terrain Park and
// Mini Mav's Pipe. 43 names have no line (bowls, glades, chutes, tree runs,
// the parks): markers at the label. One area, Steamboat, as the report has it.
// x/y/baseY/width are unused layout fields.
